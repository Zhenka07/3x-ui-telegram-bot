# Участие в разработке

[English version](CONTRIBUTING.en.md)

1. Создайте issue с описанием задачи или ошибки.
2. Создайте отдельную ветку для изменений.
3. Не добавляйте секреты, токены и реальные клиентские ссылки.
4. Добавьте автоматические тесты на изменяемое поведение.
5. Выполните `go test ./...` и `go vet ./...` перед отправкой кода.
6. В pull request опишите совместимость с 3x-ui и способ ручной проверки.

Для изменений API панели используйте обезличенные тестовые данные. Реальные UUID, пароли, Reality-ключи, Telegram-токены, IP-адреса серверов и файлы `x-ui.db` строго запрещены в issues и commits.

Все функции и методы должны содержать стандартные doc-комментарии Go на английском языке, а лишние комментарии внутри функций не допускаются.
