# Политика безопасности

[English version](SECURITY.en.md)

## Сообщение об уязвимости

Не публикуйте рабочие эксплойты, токены, пароли или данные панелей в публичных issues. Используйте механизм GitHub Private Vulnerability Reporting в разделе Security репозитория либо свяжитесь с мейнтейнером приватно.

## Поддерживаемые версии

Исправления безопасности выпускаются только для актуального стабильного релиза проекта.

## Обязательные правила эксплуатации

- держите веб-панель 3x-ui за firewall или на локальном адресе `127.0.0.1`;
- обязательно ограничивайте доступ к боту через белый список Telegram ID `ADMIN_IDS`;
- включайте проверку TLS-сертификата для публичных HTTPS-панелей;
- ограничивайте права на конфигурационный файл командой `chmod 600` для `.env`;
- регулярно обновляйте пароли администратора панели и токен бота;
- запускайте сервис бота от имени отдельного непривилегированного пользователя;
- никогда не коммитьте в Git файлы конфигурации `.env` и базы данных `*.db`.
