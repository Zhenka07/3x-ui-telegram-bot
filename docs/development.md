# Разработка

[English version](development.en.md)

## Требования к окружению

Для сборки и разработки проекта требуются Go 1.22+ (рекомендуется Go 1.25), Git и доступ к панели 3x-ui для сквозного тестирования:

```bash
git clone https://github.com/Zhenka07/3x-ui-telegram-bot.git
cd 3x-ui-telegram-bot
```

## Запуск тестов и проверки

Проект содержит автоматические unit-тесты, не требующие внешних сетевых сервисов:

```bash
go test -v -count=1 ./...
```

Статический анализ кода выполняется встроенным инструментом `go vet`:

```bash
go vet ./...
```

## Сборка бинарных файлов

Сборка статического бинарника без CGO для целевой архитектуры Linux amd64:

```bash
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -ldflags="-s -w" -o admin-bot ./cmd/admin
```

## Стандарты кодовой базы

- все функции и методы документируются стандартными комментариями Go на английском языке (`// FunctionName ...`);
- пояснительные комментарии внутри тел функций строго не допускаются;
- для работы с базой данных используется pure-Go драйвер `modernc.org/sqlite` без зависимости от CGO;
- сообщения для Telegram форматируются в HTML с экранированием пользовательских строк через `escapeHTML`.
