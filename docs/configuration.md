# Конфигурация

[English version](configuration.en.md)

## Переменные окружения

| Переменная | Назначение | По умолчанию |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | обязательно |
| `ADMIN_IDS` | Список Telegram ID администраторов через запятую | обязательно |
| `XUI_BASE_URL` | Полный базовый URL панели 3x-ui | обязательно |
| `XUI_USERNAME` | Логин учётной записи администратора 3x-ui | `admin` |
| `XUI_PASSWORD` | Пароль учётной записи 3x-ui | обязательно |
| `XUI_INSECURE_SKIP_VERIFY` | Отключение проверки TLS (для самоподписанных сертификатов) | `false` |
| `SERVER_HOST` | Публичный IP-адрес или доменное имя для сборки VLESS-ссылок | обязательно |
| `DB_PATH` | Путь к файлу базы данных SQLite (серверы и аудит) | `data/admin.db` |
| `XUI_TIMEOUT` | Таймаут выполнения HTTP-запросов к панели 3x-ui | `20s` |
| `TELEGRAM_POLLER_TIMEOUT` | Таймаут ожидания обновлений long polling | `10s` |
| `LOG_LEVEL` | Уровень детализации логов (`debug`, `info`, `warn`, `error`) | `info` |
| `SSH_ENABLED` | Включение безопасного подключения через SSH-туннель | `false` |
| `SSH_HOST` | Хост/IP-адрес сервера для SSH-подключения | `${SERVER_HOST}` |
| `SSH_PORT` | Порт SSH-сервера | `22` |
| `SSH_USER` | Имя пользователя SSH | `root` |
| `SSH_KEY_PATH` | Путь к приватному ключу SSH (OpenSSH / PEM) | опционально |
| `SSH_PASSWORD` | Пароль пользователя SSH (если ключ не задан) | опционально |


## Безопасность файлов конфигурации

- файл `.env` содержит чувствительные секреты и должен быть защищён правами `0600`;
- директория базы данных `data/` создаётся приложением автоматически с правами `0700`;
- никогда не передавайте токены Telegram и пароли панели через открытые каналы связи.
