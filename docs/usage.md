# Использование

[English version](usage.en.md)

## Главное меню и команды

```text
/start    - главное интерактивное меню управления
/inbounds - список и управление подключениями (inbounds)
/servers  - список серверов и переключение активного сервера
/search   - глобальный поиск клиента по email или UUID
/status   - мониторинг нагрузки сервера, статус Xray и обновления
/logs     - просмотр журнала логов сервера (напр. /logs 100)
/help     - справочная информация по возможностям бота
```

## Управление несколькими серверами (Мультисерверность)

- Команда `/servers` или кнопка `🌐 Серверы` открывает список подключенных хостов 3x-ui.
- Зелёная отметка `✅` указывает текущий активный сервер.
- Нажатие на сервер мгновенно переключает рабочее окружение бота без перезапуска сервиса.
- Конфигурация основного сервера автоматически синхронизируется с `.env` при старте.

## Мастер создания подключений (Inbound Wizard)

1. Введите понятное название подключения (Remark, от 2 до 64 символов).
2. Выберите сетевой порт: кнопка случайного свободного порта (15000–55000), порт 443 или ручной ввод.
3. Выберите домен маскировки Reality: встроенные пресеты (`apple.com`, `yahoo.com`, `gateway.icloud.com`, `dl.google.com`) или ручной ввод.
4. Бот автоматически запрашивает или локально генерирует пару ключей X25519 и 16-значный Short ID.
5. Проверьте параметры на карточке подтверждения и нажмите кнопку создания.

## Управление клиентами и ссылки

- **Индикаторы онлайн-статуса**:
  - `🟢` — клиент онлайн (передает трафик прямо сейчас);
  - `⚪` — клиент активен, но не подключен;
  - `⏸` — клиент временно отключен администратором.
- **Глобальный поиск**: команда `/search` или кнопка `🔍 Поиск клиента` ищет клиента по совпадению подстроки в email или UUID по всем инбаундам.
- **Поддержка протоколов и подписок**:
  - Автоматическое использование нативных ссылок подписки `subLinks` от 3x-ui.
  - Универсальная генерация ссылок подключения: VLESS (Reality и TLS), VMess, Trojan, Shadowsocks.
  - Мгновенная генерация QR-кода прямо в чат Telegram.
- **Действия с клиентом**: включение/отключение, сброс счётчиков трафика, продление срока действия и удаление с подтверждением.

## Системный мониторинг, логи и аудит

- **Мониторинг нагрузки (`/status`)**: потребление CPU, RAM, дискового пространства, системный Uptime и статус ядра Xray.
- **Проверка обновлений**: проверка свежих релизов 3x-ui через GitHub API с уведомлением о доступности новой версии.
- **Просмотр логов (`/logs`)**: чтение системных журналов `journalctl -u x-ui` через SSH-туннель или через API панели. При объёме лога свыше 3500 символов бот автоматически формирует и отправляет файл `server-logs.txt`.
- **Журнал аудита**: автоматическая фиксация каждого административного действия в локальной базе SQLite (`audit_logs`).
